# Card viewer for A Distant Plain.

I created this small tool to make A Distant Plain more accessible for players who may have difficulty reading the physical cards clearly or remembering their effects during play.

It shows two separate card panels: one for the current event and one for the next event. Swipe left or right to switch between them, then use the bottom controls to select a different card in the active panel.
The ? button opens the background text for the displayed card taken from the Playbook.

The app supports Polish and English, and remembers the selected language and cards between visits.
Polish card translations are thanks to user Bambrough.
